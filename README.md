# 🏦 大富翁 · 世界银行刷卡版（8 人联机）

Designed by Jeremy

## 一、怎么开一局（只需要一台电脑当"主机"）

**第 1 步：主机安装 Node.js（只装一次）**
打开 https://nodejs.org ，下载 **LTS** 版本，一路"下一步"装好。

**第 2 步：启动游戏**
- **Mac**：双击 `启动游戏.command`
  （第一次如果提示"无法打开"：右键点它 → 打开 → 再点"打开"）
- **Windows**：双击 `启动游戏.bat`

窗口里会显示类似这样的地址：
```
本机打开：  http://localhost:3000
同一 WiFi： http://192.168.1.23:3000
```
⚠️ 玩游戏时这个窗口不要关，关了服务器就停了。

**第 3 步：大家进房间**
1. 主机在浏览器里打开 `http://localhost:3000`，填名字，点"创建房间"，会得到 4 位房间号。
2. 其他 7 个人用自己的电脑，在浏览器（Chrome / Safari / Edge 都行）打开"同一 WiFi"那行地址，填名字和房间号，点"加入"。
3. 每人选颜色和棋子，房主点"开始游戏"。

> 如果朋友打不开：检查是不是连着同一个 WiFi；Windows 主机第一次启动时如果弹出防火墙提示，要点"允许访问"。

## 二、不在同一个地方怎么玩（部署到网上）

把游戏放到免费的云服务器 Render 上，大家用同一个网址就能玩：
1. 注册 GitHub，新建一个仓库，把这个文件夹的所有文件上传进去（不用传 `node_modules`）。
2. 注册 https://render.com → New → **Web Service** → 选择这个仓库。
3. 设置：Build Command 填 `npm install`，Start Command 填 `npm start`，选 Free（免费）套餐。
4. 等它部署完，会得到一个 `https://xxxx.onrender.com` 的网址，发给朋友就行。

> 免费版 15 分钟没人用会休眠，第一次打开要等大概 1 分钟。玩的过程中不会休眠。

## 三、玩法

| 现实中 | 游戏里 |
|---|---|
| 掷骰子 | 点"🎲 掷骰子"或按 **空格**，3D 骰子会滚动 |
| 刷卡付钱 | 棋盘中间出现你的银行卡，**拖进刷卡机**（或者直接点它） |
| 收钱 | 刷卡机自动插入收款人的卡，显示 +金额，发出"嘀"声 |
| 机会 / 命运卡 | 卡片翻转出现，所有人都能看到 |
| 买地 / 拍卖 | 踩到空地时弹出地契，可以买或拍卖，拍卖时所有人一起出价 |
| 建房 / 抵押 | 点棋盘上自己的地，或右边"我的地产" |
| 玩家间交易 | 点"🤝 交易"，勾选地产 + 填现金，对方接受才成交 |
| 破产 | 钱不够又没东西可卖时，点"宣布破产" |

**规则要点（v9）**
- 金额单位 K / M / B。每人起始 300M，地价 60M–420M（平均约 240M），开局只够买 1–2 块地；经过「起点」或内圈「环球中心」领取工资 60M，同时按名下地产现值缴纳**地产税**：第 1 阶段 4%，每次通胀 +1.5 个百分点，最高 16%。
- **首富**：总资产（现金 + 地产 + 房屋 + 股票持仓 − 贷款）率先达到 **100B** 者成为富翁胜出，其余玩家继续对战，依次决出名次。
- **破产**：破产者出局，其地产转为半价"法拍房"。只剩一人时结束。
- **通货膨胀**：每 10 分钟一次（房主也可用「进程加速器」触发）。地价、房价 ×1.7，租金、工资、税费、卡牌奖惩 ×1.5；此外地价、房价每分钟自然上涨 1%。越到后期，买地盖房越吃力。
- **建房阻力**：同一块地越往上盖越贵（第 1–4 栋造价 ×1 / ×1.3 / ×1.7 / ×2.2，酒店 ×3）；全场已盖的房屋越多，建材越紧缺，造价最高再 ×2。
- **回合自动结束**：掷骰并处理完当前格子后，自动轮到下一位玩家；建房、交易、金融操作随时可做。
- **远程购买**：在地产交易所可提前买下银行持有的地产，价格为现价的 3 倍。
- **房屋收益**：每栋房屋每秒产生收益（约 100 秒回本），酒店为 5 倍。
- **金融中心**：三个功能直接放在操作区——📈 股票（按 F，6 只股票实时行情，可买卖）、🎯 涨跌竞猜（按 G，10 秒后结算，猜中返还 1.9 倍，结算时全屏显示结算报告）、🏦 银行贷款（按 L，额度为总资产一半，每分钟复利 3%）。
- **互动表情**：24 个表情，每个都有专属的飞行轨迹、落点特效和音效（雷劈、炸弹、冻住、撒钱、王冠……）。
- **三个钱包**：银行卡 / 手机 / 现金，部分机会牌、命运牌只影响其中一个钱包，需要合理分配资金。
- **互动**：点玩家可发表情或 20 字以内的文字（全体可见），也可转账。房主可随时移出任何玩家。
- 右侧各面板点击即可放大查看详情；支持手机浏览器（竖屏自动切换布局）。

**断线了怎么办**：用同一台电脑、同一个浏览器重新打开网址，会自动回到原来的位置。如果有人一直掉线，房主可以点"跳过掉线玩家"。
**想提前结束**：房主点"结束并结算"，按总资产（现金 + 地产 + 房屋）排名。

## 四、文件说明
- `server.js`：联机服务器
- `game.js`：游戏规则（所有点数、余额都由服务器计算，没法作弊）
- `public/data.js`：棋盘、地价、租金、机会卡、命运卡（想改数值改这里）
- `public/landmarks.js`：各城市地标图标
- `public/app.js`、`style.css`、`index.html`：画面和动画
- `test/sim.js`：8 个机器人自动对局的测试，运行命令是 `node test/sim.js`
- **对局复盘清单**：每局结束后自动弹出，包含最终名次（达成目标/出局时间、最高总资产）、本局奖项、每位玩家的地产/收入/支出/金融/运气明细与复盘要点、最贵的租金和关键时刻时间线，可一键复制文字版。
- **房主权限**：房主即使破产或已胜出，仍可启动进程加速器、跳过掉线玩家、移出玩家和结束结算。
- **省电**：默认去掉了会持续重绘的背景动画；右上角 🍃 可开启省电模式，关闭全部装饰动画和毛玻璃。
